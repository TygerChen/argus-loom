# 新手指南 · argus-loom 后端读代码路线图

> 本文是给零基础/刚接手的人看的**地图**：先看什么、按什么顺序、从哪几个入口把整条业务串起来。
> 配合《中文注释周计划》里的「二周日学习顺序」一起用。

## 一、一句话认识这个系统

一个**「知识库 + 在线表格 + AI 助手」一体化的 B 端应用后端**。

用户可以：把文档 / Excel 传上来 → 建知识库 → 问一句「这个月工资多少」→ 系统先**检索到相关数据/片段**，再调用**大模型**拼出答案，并把答案、引用证据、历史问答都管理起来。同时 Excel 支持多人协作编辑、分版本、权限隔离、导出、审计。

> 直白说：**这是一个给「财务重、知识多、想用 AI 检索-问答」的场景做的数据平台。** 财务数据有强隔离红线，要特别小心。

## 二、技术栈速览（认识关键词）

| 技术 | 在这里管什么 |
|---|---|
| Java 21 + Spring Boot 3 | 主语言，Web/依赖注入/IOC |
| Spring Security + JWT | 登录与会话：`auth`/`user` 模块 |
| MyBatis-Plus | DB 访问，所有 `*Mapper` 上层 CRUD |
| PostgreSQL + pgvector | 关系库 + 向量检索（把「语义相近」的片段找出来） |
| Elasticsearch | 全文检索 / 关键词检索（和向量互补） |
| MinIO / S3 | 对象存储：原文件、图表、分片存这里 |
| LangChain / 自研 Agent 图 | AI 助手（`assistant`）+ 工具调用 |
| Agnes（OpenAI 兼容） | 大模型调用统一网关（文生文/文生图/文生视频） |
| WebFlux / Reactor | 流式回答（SSE / Streaming 接口） |

## 五、一条端到端主线（心游）

跟着「**登录 → 传 Excel → 财务导入 → 问 AI 工资**」把系统串起来：

1. **登录** → `POST /api/auth/login` → `AuthController.login` → 校验账号密码 → 签发 JWT。之后每个请求带着 token，由 `JwtAuthenticationFilter` 拦截校验。
2. **上传 Excel** → `POST /api/excel/upload` → `ExcelFileController.upload` → `ExcelParserService` 解析 → Excel 各 Sheet 存为 `ExcelSheet`、版本 `ExcelVersion`、分块 `ExcelSheetChunk`，原文件进 MinIO。同步建索引以便后续可被问答检索到。
3. **财务导入** → `POST /api/finance/import` → `FinanceImportService` 把薪资表/考勤表解析成 `EmployeePayroll`/`EmployeeAttendance`，带去重指纹与批次版本；`FinanceReportController` 提供薪酬/考勤的查改入口。这里强隔离（对照红线）。
4. **问 AI** → `POST /api/assistant/chat`（或 `/api/qa/ask`）→ 助手/问答服务：
   - 先**回忆**：短期记忆 Hook 从会话要近期消息 + 紧凑摘要；长期记忆 `MemoryRetriever` 跨会话检索。
   - **检索**：`qa/engine` 的 `HybridChunkRetrievalService` 用 pgvector 向量 + Elasticsearch 关键词——两条通道候选合并（RRF 融合），再 `RerankingService` 重排。
   - **拼证据** → 组装上下文 → 调模型（`engine/ModelGateway`，底层走 Agnes）→ 生成回答。
   - **产证据**：`EvidenceAssessor` / `CitationAssembler` 评估与引用，把答案、证据概览返回前端。
5. **权限/审计**：整个过程中 `ExcelPermissionService`/`DocumentRoleGate` 决定谁能碰那个文档/数据，`OperationLog` 记录操作。**这是财务隔离红线，改代码前必读。**

## 七、常见「卡壳点」（新手容易踩）

1. **编译要 JDK21**：先 `export JAVA_HOME='C:\Users\yuanchentai\.jdks\corretto-21.0.11'` 再 `./mvnw -o`，否则 javac 崩溃。
2. **不能 `git`**：仓库没有 `.git`；用 `check-english-comments.py` 或 `grep` 自证改动。
3. **财务红线**：`ExcelPermissionService.userCanAccessible`/`DocumentRoleGate` 判定实现**永不改**，只加注释/测试 mock 放行。
4. **全量测试**：`./mvnw -o test`（当前 1518 全绿，0 失败）。每批改动都跑一遍护栏。
5. **端到端找断层**：前端调不通时，先看是不是 Controller 路径对不上（对照本文件第四节），再用 Chrome 网络面板看 4xx/5xx。

## 八、读完你该拐走的「骨架心智模型」

```
【JWT 鉴权】             /api/auth/login → token → 后续请求带 token
【上传&切块】  ExcelParser → ExcelDocument/Sheet/Chunk（+ ES 索引入 pgvector）
【财务库】    FinanceImport → FinanceReport / 薪酬考勤表
【RAG 问答】  检索(混合) → 重排 → 拼上下文 → 调模型 → 出答案+证据
【记忆】      短期 Hook + 长期 MemoryRetriever
【权限&审计】  ExcelPermission / DocumentRoleGate / OperationLog
```

顺着这条链看代码，整个项目就能看懂 80%。
