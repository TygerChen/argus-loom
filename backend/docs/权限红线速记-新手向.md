# 权限红线速记（新手向）：谁到底能不能看这个数据

> 这是整个系统里**最不该改**、也最该先看懂的两处判定。做任何涉及"谁能读哪个文档/哪些钱"的功能前，先回来对照这份。
> 两条线管两类数据，判定点完全不同，不要混。

---

## 先分清两条线（很多新手一开始会混）

| 线 | 管什么 | 判定类 | 门的含义 |
|---|---|---|
| **检索门槛线** | 知识库/文档「能不能进 RAG 检索」 | `document/security/DocumentRoleGate` | 按「文档要求的角色」过滤 |
| **权限档位线** | Excel 文档「能看/能改/能管理」 | `excel/service/ExcelPermissionService` | 「财务门禁 + 所有者/管理员/ACL」 |

一个管「检索前能不能看到候选」，一个管「拿到文档后能干嘛」。权限最终由**后者**决定。

---

## 线 A · ExcelPermissionService（财务隔离核心）

一句话：**财务文件只让 FINANCE 角色碰**；其余文档按「管理员 > 创建者 > ACL 授权」分级。

### 判定顺序（`permissionOf`，返回 owner / editor / viewer / null）

1. **门禁** `userCanAccessDocument`：文档是「财务文件」（`financeRequired=true`）？
   - 是 → 只有 `SystemRole.FINANCE` 能进，否则直接 **null（无权）**。
   - 否 → 放行进下步。
   - 这就是**财务隔离红线**第一道锁。
2. **财务专属**：若文档是财务文件且当前是 FINANCE → 直接 **owner**。
3. **管理员**：`ADMIN` → **owner**。
4. **创建者**：`creatorId == 自己的userId` → **owner**。
5. **兜底查 ACL**：查 `ExcelDocumentPermission` 表里这条「文档×用户」记录：
   - 没记录 → **null（无权）**；
   - 有记录 → 按其 `role`（默认 viewer）。

### 三个常用判断
- `canView`  =  `permissionOf != null`（有任一档就可见）。
- `canEdit`  =  `owner` 或 `editor`（或本人是 ADMIN）。
- `canManage` =  `owner`（或 ADMIN）。

> 🚨 注意红线：`userCanAccessDocument` 的实现（财务文件只放 FINANCE）**永远不改**。要改权限行为时，test 里 mock 放行即可，不要动判定。

---

## 线 B：DocumentRoleGate（检索门槛）

一句话：**检索时只把「该角色够得着」的文档放进候选**；无权≠拒绝，而是「让受限文档从结果里消失」，避免试探存在性。

### 角色优先级（`allowedRoleNames` 单一权威）
```
USER    → 可见 {USER} 门槛
FINANCE → 可见 {USER, FINANCE}
ADMIN   → 可见 {USER, FINANCE, ADMIN}
```

### 关键判定
- `currentRole()`：未认证或角色缺失 → 一律 `USER`（**fail-closed 最低权限**）。
- `allowedDocumentIds(groupId, role)`：查询该组内 `required_role ∈ 允许集合` 且 `READY` 未删除的文档 ID 集。groupId 非法 → 空集。
- `canRead(role, requiredRole)`：门槛为 null → 放行；否则 `allowedRoleNames(role)` 是否含该门槛。用作直接访问单文档前的二次保险。

> 🚨 关键设计：**「无权」==「当作查无此文」**。不让报错，也不让空集有差异——杜绝通过接口差异去探测「有没有一份财务文件存在」。这个「防存在性泄露」的红线逻辑**不能改**。

---

## 给新手的三个直觉对照

1. **想偷看老板的薪酬表？** 那文档 `financeRequired=true`，而你的角色是 USER → `userCanAccessDocument` 直接 null；连检测你都拿到空/null，你都分不清是「没有」还是「无关」。
2. **财务工作人员**：FINANCE → 财务文件给 **owner**（全权管理），普通文件也放开。
3. **系统管理员 ADMIN**：对每个档都拿 owner，但财务门禁**仍然先拦**——ADMIN 也要先通过第 1 道财务文件判定（这里是 FINANCE 才进）。

---

## 两处「千万不能动」的判定（红线固化）

1. `ExcelPermissionService.userCanAccessDocument` —— 财务门禁（FINANCE 才能进财务文件）。
2. `DocumentRoleGate` 的 `allowedRoleNames`/`currentRole`/`canRead`/`allowedDocumentIds` —— 角色优先级、fail-closed、防存在性。

**做测试时**：OK，mock 放行判定返回即可；**上手改判定实现**：先读一遍本档，并再三确认你不是在动红线逻辑。
