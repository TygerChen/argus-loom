# 安全回归清单

每次发版前逐项打勾，任一失败不得发版。

## 权限（IDOR）
- [ ] 普通用户访问他人财务文档/工作簿/工作表/版本/导出任务 → 403/404
- [ ] 普通用户调用财务 API（含分析、期间开关）→ 403
- [ ] 被移除权限后引用不可见（CITATION_ACCESS_REVOKED 语义）
- [ ] WebSocket 订阅他人文档 → 拒绝

## 注入与伪造
- [ ] Markdown/HTML XSS：答案与评论中的脚本不执行（净化测试覆盖）
- [ ] 私网 URL（SSRF）：网页搜索/远程抓取走公网白名单
- [ ] 协同消息伪造 userId → 服务端以会话身份覆盖

## 资源限制
- [ ] 压缩炸弹（解压超限）→ 拒绝且服务不 OOM
- [ ] 超大文件上传 → FILE_LIMIT_EXCEEDED
- [ ] 超大批量协同消息 → 限流触发且正常用户不受影响

## 传输与存储
- [ ] 生产 Cookie Secure + HttpOnly；JWT 密钥来自环境变量
- [ ] CORS/WebSocket 来源白名单生效，`*` 仅限开发
- [ ] 日志无密钥/Token/连接串
